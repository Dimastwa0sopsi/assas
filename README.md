# GIMVERSE — 3D-платформа игр

Roblox-подобная платформа на **three.js + Vite** (без фреймворков и без внешних ассетов — вся графика и звук генерируются кодом).

**Живой редактор карт:** [GimPrograms 3D Editor](https://dimastwa0sopsi.github.io/Gim-Builder/) · [исходный код редактора](https://github.com/Dimastwa0sopsi/Gim-Builder)

---

### Две 3D-игры

1. **🏔️ Небесный паркур** — башня над облаками: чекпоинты, монеты, движущиеся платформы (перевозят игрока), жизни, таймер, финишный подиум с наградой. Работает и на **любой импортированной карте** — тогда трасса строится по вашим блокам.
2. **💎 Кристальная арена** — 90 секунд против трёх ботов с ИИ: кристаллы, комбо, четыре бонуса (магнит, ускорение, заморозка, ×2), толчки от ботов, таблица результатов.

### Путь карты из редактора в игру

1. В GimPrograms 3D Editor собрать карту → **📋 Скопировать JSON**.
2. GIMVERSE → **Разработка → Импорт и публикация** → вставить JSON → «Разобрать».
3. Проверить в 3D-превью и «Тест-драйве».
4. Заполнить название, описание, иконку (эмодзи + цвет или картинка) и донаты.
5. **🌐 Выложить в сеть** — карта уходит в каталог и подключённым игрокам.

Поддерживается формат редактора: `{ version: 2, items: [{ kind, pos, rot, scale, color, physics, faces, faceFlip }] }`, а также v1 (голый массив) и обёртка `{ map: { items } }`. Блоки с текстурами на гранях и динамические (`physics: true`) блоки обрабатываются: первые получают свои материалы, вторые падают при старте игры.


## Онлайн-режим

Клиент подключается к `wss://sandbank-economic-zeppelin.ngrok-free.dev` (адрес меняется в Настройках).

- автопереподключение с экспоненциальной задержкой, heartbeat и замер пинга;
- для доменов `ngrok` автоматически добавляется `?ngrok-skip-browser-warning=1`;
- если сервер недоступен — включается **локальный режим** (BroadcastChannel): игроки в соседних вкладках браузера видят друг друга, чат и карты работают;
- публикации, отправленные без сервера, попадают в очередь синхронизации и уходят сами после подключения;
- протокол терпим к чужим серверам: неизвестные сообщения игнорируются, поэтому игра никогда не ломается из-за сервера.

Сообщения: `hello`, `welcome`, `state` (позиция ~10 Гц), `chat`, `map.publish`, `map.remove`, `invite`, `announce`, `admin.action` (ban/unban/mute/unmute/role/kick/map.moderate), `ping/pong`.

## Архитектура

```

  style.css            импорт дизайн-системы (styles/tokens|ui|views.css)
  core/
    store.js           состояние + localStorage, миграции, профиль, библиотека, админка
    net.js             WebSocket + резервный BroadcastChannel, протокол, reconnect
    ui.js              гиперскрипт h(), тосты, модалки, файлы, форматирование
    input.js           клавиатура (по e.code — раскладка не важна), мышь, тач-джойстик
    audio.js           синтез звуков на Web Audio
    library.js         каталог игр, карточки, окно игры, донаты
  three/
    engine.js          рендерер, небо-шейдер, свет, PhysicsWorld (пространственный хэш),
                       PlayerController (AABB, coyote-time, авто-подъём), CameraRig, частицы
    avatar.js          сборка персонажа, анимации, текстура лица, 2D-портрет
    mapLoader.js       парсер/валидатор JSON GimPrograms, инстанс-меши, симуляция физ-блоков
    preview.js         один общий WebGL-контекст для всех 3D-превью
  games/
    obby.js            «Небесный паркур»
    arena.js           «Кристальная арена» + ИИ ботов
  screens/             home, avatar, games, dev, online, admin, settings
  game.js              игровой рантайм: HUD, пауза, награды, сетевые игроки, донаты
tests/                 node:test — логика + интеграция интерфейса (jsdom + заглушка WebGL)
```

### Технические решения

- **Физика без библиотек:** персонаж — AABB, мир — пространственный хэш, разрешение по осям, coyote-time, буфер прыжка, авто-подъём на ступени до 0.42 м.
- **Производительность:** блоки карты без текстур собираются в `InstancedMesh` по цветам, материалы кэшируются, тени центрируются вокруг игрока, качество (`low/medium/high`) меняет pixel ratio, тени и дальность тумана.
- **Один WebGL-контекст на превью:** картинка переносится в нужный `canvas` через `drawImage`, поэтому редактор персонажа, превью карты и герой на главной не плодят контексты.
- **Доступность и адаптивность:** фокус-состояния, `aria-*` на переключателях, сайдбар на десктопе и таб-бар на мобильных, тач-джойстик в играх, уважение к `prefers` через настройку «Анимации интерфейса».

## Тесты

```
npm test
```

- `tests/logic.test.mjs` — разбор всех вариантов JSON редактора, починка битых данных, валидация и лимиты, примеры карт, сборка сцены с коллайдерами, падение динамических блоков, физика персонажа (приземление, стена, прыжок, ступенька), хранилище.
- `tests/ui.test.mjs` — приложение целиком стартует в jsdom: оболочка, все экраны, покупка в магазине, импорт JSON → публикация (с проверкой, что сообщение ушло в сокет), модерация, объявления, настройки, приём игроков/карт/чата с сервера, запуск и выход из игры.

> Проверено: `npm run build` (чистая сборка) и `npm test` — 28/28. Реальное соединение с ngrok-сервером из песочницы не проверялось (нет доступа к внешним хостам) — клиент написан так, что при недоступном сервере игра и публикация продолжают работать в локальном режиме.
